# 微信小程序用户信息获取限制说明

## ⚠️ 重要变更

**微信已完全禁止小程序自动获取用户真实头像和昵称！**

这是微信官方在 2021 年后的重大政策调整，目的是保护用户隐私。

---

## 📋 政策变更时间线

### 2021年4月13日
- 废弃 `wx.getUserProfile` API
- 小程序无法再弹窗要求用户授权获取真实信息

### 2022年10月
- `type="nickname"` 输入框只返回 "微信用户"
- `open-type="chooseAvatar"` 只能选择本地照片，无法获取微信头像

### 2023年后
- **完全禁止**小程序获取用户在微信中的真实头像和昵称
- 只能让用户**手动输入**或**从相册选择**

---

## 🚫 已废弃的方式

以下方式**全部失效**：

```javascript
// ❌ 已废弃 - 不再工作
wx.getUserProfile({
  desc: '用于完善用户资料',
  success: (res) => {
    // res.userInfo 只返回匿名信息
  }
});

// ❌ 已废弃 - 不再工作
wx.getUserInfo({
  success: (res) => {
    // res.userInfo 只返回匿名信息
  }
});
```

```xml
<!-- ❌ 无法获取真实昵称 -->
<input type="nickname" />  <!-- 只返回 "微信用户" -->
```

## ✅ 当前可行的方案

### 方案 1：让用户手动输入和选择（推荐）

这是目前**唯一**可行的方案：

**头像：**
```xml
<button open-type="chooseAvatar" bindchooseavatar="onChooseAvatar">
  <image src="{{avatarUrl}}"></image>
</button>
```
用户从**相册选择照片**，不是微信头像。

**昵称：**
```xml
<input placeholder="请输入昵称" bindblur="onNicknameBlur" />
```
用户**手动输入**昵称，不是微信昵称。

### 方案 2：使用手机号（需要企业认证）

需要：
- 小程序主体为企业
- 通过微信认证
- 每次调用收费

```xml
<button open-type="getPhoneNumber" bindgetphonenumber="getPhoneNumber">
  获取手机号
</button>
```

后端可以通过手机号查询用户信息，但仍然**无法获取微信头像和昵称**。

### 方案 3：第三方登录

让用户使用 QQ、微博等第三方账号登录，获取那些平台的头像和昵称。

但这需要额外的开发工作和第三方平台审核。

---

## 💡 本项目的解决方案

**采用方案 1：用户手动输入和选择**

### 用户流程：

1. **登录** → 点击"微信一键登录" → 获取 openid（不含头像昵称）
2. **设置头像** → 个人中心 → 点击头像 → 从相册选择照片
3. **设置昵称** → 个人中心 → 点击昵称输入框 → 手动输入名字
4. **保存** → 自动保存到云数据库和本地存储
5. **显示** → 所有页面显示用户设置的头像和昵称

### 优点：
- ✅ 完全符合微信政策
- ✅ 用户可以自定义头像和昵称
- ✅ 随时可以修改
- ✅ 不需要企业认证
- ✅ 完全免费

### 缺点：
- ❌ 无法自动获取微信真实信息
- ❌ 用户需要手动设置（多一步操作）

## 🎯 用户体验优化建议

### 1. 引导用户设置

登录成功后，弹窗提示：
```
登录成功！请前往个人中心设置头像和昵称
[去设置] [稍后]
```

### 2. 提供默认头像

用户没设置时，显示：
- 默认头像图标
- "点击设置头像"
- "点击输入昵称"

### 3. 简化设置流程

- 点击头像 → 直接打开相册
- 点击昵称 → 直接进入输入状态
- 自动保存，无需额外操作

### 4. 提醒未设置用户

首页或其他页面提示：
```
[头像图标] 完善你的个人资料，让简历更完整 >
```

## 🤔 常见问题

### Q: 为什么别的小程序可以获取我的头像和昵称？

A: 那些是**老版本**小程序，在 2021 年之前发布的。新版本和新发布的小程序都无法获取。

### Q: 我看到有些小程序显示我的微信头像？

A: 那可能是：
1. 你之前授权过（老数据）
2. 使用了企业认证 + 手机号方案
3. 是微信官方自己的小程序（特权）

### Q: 能不能通过其他技术手段获取？

A: **不能！** 这是微信的隐私保护政策，任何绕过的方式都会被封禁。

### Q: 用户觉得手动输入很麻烦怎么办？

A: 这是所有小程序都面临的问题。可以：
1. 优化引导流程
2. 提供快捷输入（常见昵称推荐）
3. 允许跳过（后续再设置）
4. 解释这是保护隐私的措施

## ✅ 总结

**现实：** 微信已经完全禁止小程序自动获取用户真实头像和昵称。

**方案：** 让用户手动输入昵称和从相册选择头像。

**体验：** 通过优化引导流程，让用户愿意主动设置。

**未来：** 微信不太可能放开这个限制，这是隐私保护的大趋势。
