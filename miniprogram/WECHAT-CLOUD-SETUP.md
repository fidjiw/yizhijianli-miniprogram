## 🔄 工作流程说明

### 用户点击登录时发生了什么：

```
用户点击登录
    ↓
前端调用 wx.login() → 获取 code
    ↓
前端调用云函数 wx.cloud.callFunction('login', { code })
    ↓
云函数收到 code → 自动获取用户的 openid
    ↓
云函数在数据库中创建/更新用户记录
    ↓
云函数返回 token（实际上就是 openid）
    ↓
前端保存 token 到本地存储
    ↓
登录成功！
```

### 用户授权头像/昵称时发生了什么：

```
用户点击授权
    ↓
前端调用 wx.getUserProfile() → 获取用户授权信息
    ↓
前端调用云函数 wx.cloud.callFunction('getUserInfo', { nickName, avatarUrl })
    ↓
云函数保存用户信息到数据库
    ↓
前端本地保存用户信息
    ↓
下次打开小程序，直接从本地读取用户信息
```

## 📊 云数据库结构

系统自动为你创建了一个 **users** 集合，包含：

```javascript
{
  _id: "xxxx",                    // 自动生成的ID
  _openid: "xxx",                 // 用户的微信 openid（唯一）
  nickName: "用户昵称",            // 用户昵称
  avatarUrl: "头像URL",            // 用户头像
  createdAt: "2026-06-08...",     // 创建时间
  updatedAt: "2026-06-08...",     // 更新时间
  lastLoginAt: "2026-06-08..."    // 最后登录时间
}
```

所有数据都自动保存在微信提供的数据库中，完全安全！

## ⚡ 常见问题

### Q1: 上传云函数时出现"没有该功能"

**A:** 这是因为你的账户权限问题。解决方案：
1. 确保是小程序主账户或有云开发权限的账户
2. 如果还是不行，在微信开发者工具中重新创建项目配置

### Q2: 登录时显示"云函数调用失败"

**A:** 检查以下几点：
1. ✅ 云环境 ID 是否正确（在 `app.js` 中）
2. ✅ 云函数是否已上传（开发者工具中看得到✓）
3. ✅ 是否在真机或开发者工具的云函数端看到错误日志

### Q3: 可以在开发者工具中看到我的数据吗？

**A:** 可以！
1. 微信开发者工具 → **云开发** → **数据库**
2. 找到 **users** 集合
3. 可以看到所有用户数据、修改、删除等

### Q4: 数据会保存多久？

**A:** 永久保存！除非你手动删除。微信云开发提供的数据库是持久化存储。

### Q5: 免费版有什么限制？

**A:** 免费版已经很宽松了：
- 每月 **100 万次** 数据库/函数调用
- **5GB** 数据库存储空间
- **5GB** 文件存储空间
- 个人项目完全够用！
