# 一纸简历 - 微信小程序

基于第一版 UI 设计稿开发的简历制作小程序

## 项目结构

```
miniprogram/
├── pages/                    # 页面目录
│   ├── welcome/             # 引导/登录页
│   ├── home/                # 首页
│   ├── templates/           # 模板库
│   ├── editor/              # 简历编辑器
│   ├── ai-optimize/         # AI智能优化
│   ├── preview/             # 简历预览
│   ├── my-resumes/          # 我的简历列表
│   └── profile/             # 个人中心
├── app.js                   # 小程序逻辑
├── app.json                 # 小程序配置
├── app.wxss                 # 全局样式
├── sitemap.json             # 站点地图
└── project.config.json      # 项目配置
```

## 开发指南

### 环境要求

- 微信开发者工具 1.05.0+
- 小程序基础库 2.24.0+
- Node.js 14+（用于后端开发）

### 本地开发

1. 下载并安装微信开发者工具
2. 导入项目目录 `miniprogram/`
3. 使用测试 AppID 或申请正式 AppID
4. 编译运行

### 代码规范

- 遵循微信小程序官方开发规范
- 组件化开发，提取公共组件
- 统一使用 rpx 作为尺寸单位
- 合理使用全局样式和页面样式

### 后端接口规范

#### 1. 用户认证

```
POST /api/auth/login
Body: { code: string }
Response: { token: string, userInfo: object }
```

#### 2. 简历管理

```
GET /api/resumes          # 获取简历列表
POST /api/resumes         # 创建简历
GET /api/resumes/:id      # 获取简历详情
PUT /api/resumes/:id      # 更新简历
DELETE /api/resumes/:id   # 删除简历
```

#### 3. AI优化

```
POST /api/ai/analyze      # 分析简历
Body: { resumeId: string }
Response: { score: number, suggestions: array }

POST /api/ai/generate     # AI生成内容
Body: { type: string, context: object }
Response: { content: string }
```

#### 4. 导出

```
POST /api/export/pdf      # 导出PDF
Body: { resumeId: string }
Response: { url: string }

POST /api/export/image    # 导出长图
Body: { resumeId: string }
Response: { url: string }
```

## 部署说明

### 小程序端

1. 完成代码开发和测试
2. 在微信开发者工具中点击「上传」
3. 登录微信公众平台
4. 提交审核
5. 审核通过后发布

### 后端服务

1. 部署 Node.js/Python 后端服务
2. 配置数据库（MySQL/PostgreSQL）
3. 配置 OSS 存储（用于简历文件）
4. 配置 AI 服务接口
5. 配置微信支付（会员功能）

## 技术栈

### 前端

- 微信小程序原生框架
- WXML / WXSS / JavaScript

### 后端（建议）

- **Node.js**: Express / Koa
- **Python**: Flask / FastAPI
- **数据库**: MySQL / PostgreSQL
- **文件存储**: 阿里云 OSS / 腾讯云 COS
- **AI服务**: OpenAI GPT-4 / 百度文心一言

### 第三方服务

- 微信开放平台（登录、支付）
- AI大模型服务
- PDF生成服务

## 注意事项

1. **appid 配置**：需要在 `project.config.json` 中配置正式的 AppID
2. **域名配置**：后端接口域名需要在微信公众平台配置服务器域名白名单
3. **隐私政策**：需要在小程序后台配置隐私政策和用户协议
4. **支付配置**：会员功能需要申请微信支付商户号
5. **内容审核**：AI生成内容需要接入微信内容安全接口
