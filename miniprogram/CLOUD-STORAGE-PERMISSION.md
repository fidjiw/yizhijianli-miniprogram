# 云存储权限配置指南

## 问题：头像上传失败或昵称保存失败

如果用户选择头像和输入昵称后，页面仍然显示"微信用户"，可能是云存储权限问题。

## 解决方案：配置云存储权限

### 步骤 1：进入云开发控制台

1. 微信开发者工具 → **云开发**
2. 选择你的云环境：`cloudbase-d1g90x9al09984900`

### 步骤 2：配置云存储权限

1. 点击 **存储** 标签
2. 点击右上角 **权限设置**
3. 添加以下规则：

```json
{
  "read": true,
  "write": "auth != null"
}
```

这表示：
- 所有人可以读取（查看头像）
- 只有登录用户可以写入（上传头像）

### 步骤 3：配置数据库权限

1. 点击 **数据库** 标签
2. 找到 **users** 集合
3. 点击 **权限设置**
4. 设置为：**仅创建者可读写**

### 步骤 4：检查云函数日志

1. **云开发** → **云函数**
2. 点击 **getUserInfo** → **日志**
3. 查看是否有错误信息

## 常见问题

### Q1: 提示"没有权限"
**A:** 需要在云开发控制台配置存储和数据库权限

### Q2: 头像显示不出来
**A:** 可能是云存储权限问题，或者 fileID 格式错误

### Q3: 昵称没有保存
**A:** 检查 getUserInfo 云函数是否正确部署和调用

## 临时解决方案

如果云存储一直有问题，可以暂时：
1. 不上传头像到云存储
2. 直接使用微信提供的临时路径
3. 只保存昵称到数据库

修改代码跳过云存储上传：
```javascript
onChooseAvatar(e) {
  const { avatarUrl } = e.detail;
  // 直接使用临时路径，不上传到云存储
  this.saveUserInfo(null, avatarUrl);
}
```
